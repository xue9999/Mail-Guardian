# Historical Linux pilot — 30 October 2026

The initial Linux pilot was deliberately inactive, with no mailbox credentials,
imported state or enabled worker. Its empty-pilot repair tool remains in
`deploy/linux/pilot_update.py` for historical/test coverage only. It refuses a
populated deployment and is not a production upgrade mechanism.

The reference deployment subsequently completed handover to a sole Linux
worker, with the Mac retired, encrypted backup/restore, monitored scheduling and
coordinated updates. Those later procedures supersede the old pilot plan.

Use the [current operations runbook](maintainers/OPERATIONS.md),
[release process](maintainers/RELEASING.md),
[migration fence](../deploy/linux/MIGRATION_FENCE.md), and
[backup format](../deploy/linux/BACKUP.md).

Qualification of an empty pilot never established production readiness.
Private mailbox histories, host identifiers and audit locations are not part
of the public source distribution.
